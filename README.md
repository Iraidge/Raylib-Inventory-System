# Raylib Inventory System

**A 2D inventory system built with C++ and raylib.**

<img width="800" height="450" alt="InventorySystemShowcase-ezgif com-video-to-gif-converter" src="https://github.com/user-attachments/assets/5a4273b8-7971-4eee-9c1d-6c83b5086620" />

## Features
- Drag&Drop with item swapping
- Item stacking system
- Individual and bulk selling mechanics
- Tooltip system on right-click
- Lazy texture loading for 1244 unique items
- Custom cursor and button animations

## Built With
- C++17
- raylib 5.5

## How to Build
**Windows (MinGW)**
```bash
mkdir build
cd build
cmake .. -G "MinGW Makefiles"
cmake --build .
```

**Linux/Mac**
```bash
mkdir build && cd build
cmake ..
cmake --build .
```
